# 운영 runbook

이 디렉터리는 운영자가 실제 작업 중 따라야 하는 절차를 둔다. 구성의 원칙과 구조 설명은 각 컴포넌트 `README.md`, 반복 실행 가능한 동작은 해당 컴포넌트의 `scripts/` 가 맡는다.

## 역할 경계

| 문서·코드 | 답해야 하는 질문 |
|---|---|
| 컴포넌트 `README.md` | 무엇을 왜 이렇게 구성했는가? |
| 컴포넌트 `scripts/` | 반복 가능한 동작을 어떻게 정확히 실행하는가? |
| `docs/runbook/` | 언제 실행하며, 전제조건·영향·검증·복구는 무엇인가? |

runbook 은 스크립트 내용을 복사하지 않는다. 실행 파일의 정확한 경로와 필요한 인자만 링크하고, 사람의 판단과 운영 안전장치를 기록한다.

## 작성 기준

각 runbook 에 다음 항목을 둔다.

1. 목적과 적용 범위
2. 전제조건과 필요한 접근 권한
3. 예상 영향과 중단 가능성
4. 실행 순서
5. 성공 판정과 검증 방법
6. 실패 시 중단 조건과 복구 절차
7. 시크릿 취급과 기록하면 안 되는 값

실제 장비에서 검증한 절차만 runbook 으로 확정한다. 아직 수행하지 않은 ACME DNS-01 같은 작업은 추측으로 절차를 만들지 않고, PoC 후 확인된 UI 경로·명령·검증 결과를 기록한다.
